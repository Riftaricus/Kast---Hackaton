# Kast Receptionist Program (For Hackaton)

## Techstack
  Made with C# with CLI
  Randomly Generated Data using a Factory class
## De Kast
  De Kast is a sportschool where with the amount of buildings they have, they have a very little amount of receptionists. This system is designed to make the job easier.
  Automating a bunch of their tasks and being a datacenter for all data relating to the sportschool.
## Launch Instructions
  You need .net installed, version 10
  Run ``git clone https://github.com/Riftaricus/Kast---Hackaton``
  Run ``cd "Kast - Hackaton"``
  Run ``dotnet run``
